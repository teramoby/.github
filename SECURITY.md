# Security Policy

This policy applies to every repository in the teramoby organization unless a repository has its own `SECURITY.md`.

## Supported versions

For each project, the latest release and the default branch receive security fixes.

## Reporting a vulnerability

Please report suspected security issues privately. Do not open a public issue.

- Email [contact@speedle.io](mailto:contact@speedle.io) with `SECURITY` in the subject.
- Or use the **Report a vulnerability** button on the affected repository's Security tab (GitHub private vulnerability reporting).

Please include:

- the affected project and version or commit;
- the component or endpoint involved;
- steps to reproduce the issue, or a proof of concept;
- the potential impact;
- any mitigation you have identified.

We aim to acknowledge new reports within 5 business days.
